Connection help

Connect to Guest WiFi

Use this quick guide to get online safely. Your host or support team can provide the current network name and password.

01

Join the network

Most devices connect in under a minute.

  1. 1

    Open Settings and select WiFi.

  2. 2

    Choose the guest network name provided by your host or support team.

  3. 3

    Enter the current guest password exactly as supplied, then wait for the connection confirmation.

  4. 4

    Open a browser and visit any page to complete a sign-in screen, if one appears.

02

Stay secure

A few simple habits keep shared WiFi safer.

  • Do not share the guest password publicly.
  • Use secure websites that show https://.
  • Disconnect when you have finished on a shared device.
Troubleshooting

Still having trouble?

Network not visible

Move closer to the router, turn WiFi off and on, then check the network list again.

Password rejected

Forget the network on your device and reconnect with the latest password from your host.

Connected, but no internet

Open a browser to check for a sign-in screen, then restart WiFi if the issue continues.
